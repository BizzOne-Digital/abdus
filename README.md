# Vote Shinwary — Ward 1, Oshawa

Campaign website for **A. Salam Shinwary**, candidate for City Councillor in Ward 1, Oshawa.

## Stack

- Vite + React + TypeScript
- Framer Motion
- Custom liquid-glass design system

## Commands

```bash
npm install
npm run dev
npm run build
```

## Replaceable assets

Place updated photos in `public/images/`:

- `candidate-hero.jpg` — hero portrait
- `candidate-podium.jpg` — Meet Shinwary section
- `community-1.jpg` / `community-2.jpg` / `community-3.jpg` — community gallery
- `ward1-map.svg` — Ward 1 map graphic
